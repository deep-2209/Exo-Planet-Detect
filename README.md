# Exo-Detect — Exoplanet Transit Detection

An end-to-end deep learning system for detecting exoplanet transits in real
telescope light curve data (NASA Kepler mission, later possibly TESS).

## What this project does

- **Deep learning** for time-series classification of light curves
  (1D CNN, potentially a transformer).
- **Classical baseline** comparison against the Box Least Squares (BLS)
  algorithm, so results are meaningful rather than a single unexplained number.
- **Cloud-native pipeline** for data and training on AWS, provisioned with
  Terraform.
- **Interactive dashboard** for exploring light curves and model predictions.
- **Research-style write-up** as the final deliverable.
